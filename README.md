# 한국어 완화표지 분석실
Windows: Python 3.10 이상 설치 후 압축을 풀고 실행하기.bat 더블클릭. 브라우저가 열리지 않으면 http://localhost:8501 접속.
직접 실행: `python -m pip install -r requirements.txt` 후 `python -m streamlit run app.py --server.maxUploadSize 500`.
Streamlit Community Cloud에 배포하려면 app.py, engine.py, requirements.txt를 GitHub 저장소에 올리고 app.py를 메인 파일로 선택한다. 연구 원자료는 저장소에 올리지 않는 것이 좋다.

사전의 표제형 (원형), 변이형 열은 필수. 변이형은 /, 세미콜론, 줄바꿈으로 구분. 차원, 유형, ID, 근거 문헌, 참고 사항은 선택. 신규 행 자동 반영. 두 시트 중 하나만 사용. 변이형을 실제 표면형으로 충분히 기재할 것. 일부 하다/되다 활용과 ㄹ/ㄴ/ㅁ 받침 표기 자동 처리. 복잡한 문법 표기와 문맥은 수동 검증 필요. 논문 엑셀은 A~F 순서 ID, 학술지, 연도, 제목, 세부분야, 초록. 기본은 헤더 없음. 파일명에 공학/인문학이 없으면 분야를 직접 지정.

문장 경계는 구두점 및 공백 기반 근사이며, 정교한 한국어 문장분리기 또는 형태소 분석기는 사용하지 않는다. 모든 탐지는 후보이며 참고 사항 전체를 자동 판정하지 않는다. 기본/별도/제외 상태를 검토하고, 무작위 표본을 내려받아 평정할 것. 100문장당 빈도와 완화후보문장 비율은 서로 다른 지표다. 결과 ZIP은 UTF-8 BOM CSV이므로 엑셀로 열 수 있다. 전체 문장 파일은 Excel 행 제한을 넘을 수 있으므로 Python/R 사용 권장. 전체 7만여 편은 메모리 여유가 있는 PC에서 실행 권장. 먼저 파일당 100행으로 점검할 것.
